# Contributing to Glowberry

Glowberry is an open, exploratory public-art project. Contributions are welcome from artists, fabricators, Newfoundland community members, curious public, and software/hardware helpers — and from coding agents working in this repo.

## Before you start

1. Read the [README](README.md) and [docs/BRIEF.md](docs/BRIEF.md).
2. Review the [Code of Conduct](CODE_OF_CONDUCT.md).
3. Check [open issues](https://github.com/adamsimms/glowberry/issues), [Discussions](https://github.com/adamsimms/glowberry/discussions), and the Projects board.
4. For large or sensitive changes (site outreach, shop contact, funding), open an issue first.

## How to help

| Kind of help | Prefer |
|--------------|--------|
| Concept spikes, site leads, fab questions | Issues (use templates) |
| Soft brainstorming | Discussions |
| Docs / typos / structure | Small PRs |
| Software (firmware, LED pulse) | Issues + PRs labeled `software` |
| Hardware BOM / solar / materials | Issues labeled `hardware` or `fabrication` |

Do **not** cold-email fabricators or landowners on behalf of the project without coordinating in an issue first.

Do **not** commit moodboard photos, location dumps, or large meshes unless an issue explicitly asks for them.

## Pull requests

1. Fork and branch from `main`.
2. Keep PRs focused (one concern).
3. Update docs when decisions change.
4. Describe what changed and why.

## Agents

See [AGENTS.md](AGENTS.md). Prefer one milestone or one issue per chat for mechanical work.

## Security

Do not open public issues for security-sensitive findings. Email **hello@adamsimms.xyz** — see [SECURITY.md](SECURITY.md).
