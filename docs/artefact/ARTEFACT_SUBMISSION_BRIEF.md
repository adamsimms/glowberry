## 1. What it is

**Glowberry** is a monumental ripe **bakeapple** (cloudberry) — a pilgrimage sculpture with soft **heartbeat / breathing glow** in the flesh at dusk and night.

| | |
|--|--|
| **Tone** | Awe + humor + uncanny presence |
| **Interaction** | Touch, sit near, walk around, photograph — **no entering** |
| **Audience** | Newfoundlanders and visitors |
| **Site** | TBD — reachable NL (Avalon / Fogo / Bonavista-class); coastal plateau character |
| **Lineage** | Continues *Cloudberry*, *Light House*, and related beacon / resettlement work |

**Not:** weather station, data dashboard, or enterable pavilion.

**References in spirit:** Kusama *Yellow Pumpkin* (pilgrimage fruit); Turrell / Villareal (night light); Kapoor *Cloud Gate* (public touchable body) — as **translucent glowing flesh**, not opaque paint or mirror steel.

## 3. Look & materials

**Target:** semi-opaque **translucent glowing orange** (amber → vermillion).

| Prefer discussing | Avoid as primary skin |
|-------------------|------------------------|
| Translucent **PETG** | Fully opaque paint |
| Thin **translucent** tinted coat + **aliphatic UV clear** | Polished stainless body |
| Translucent **FRP** if print isn’t right for outdoor NL | |

Daytime: readable fruit. **Night: the show.** Occasional dark nights OK outdoors.
