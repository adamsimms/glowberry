## 2. How continuous-air art inflatables work

Two common systems:

| Type | How it holds shape | Best for |
|------|--------------------|----------|
| **Continuous blower (open / leaky by design)** | Small centrifugal **fan** runs 24/7; air escapes at seams/vents; form stays plump | Outdoor art, event fruit, Choi-style pieces — **default for this track** |
| **Sealed airtight bladder** | Inflate once; hold pressure; occasional top-up | Balloons, some boats — harder at organic berry scale; less “alive” |

**Default for Glowberry Inflatable:** continuous-air shell + one (or two) quiet outdoor blowers at the stem/base.

```text
[AC or generator] ──► [blower(s)] ──► [air sock / duct] ──► [stem / base inlet]
                                                              │
                                                    fabric berry (slightly porous /
                                                    vented so it doesn’t balloon-explode)
                                                              │
                                                    [ground anchors / ballast]
```

Optional night: cheap internal LED string / flood in the base → soft glow through translucent PVC or lit ripstop (secondary; not required for POC).

## 3. Material

| Option | Feel | Build method | Outdoor summer | Notes |
|--------|------|--------------|----------------|-------|
| **PVC-coated polyester / vinyl tarpaulin** (~0.3–0.5 mm, orange tint or printed) | Glossy Pop fruit; Choi-adjacent | **Hot-air / RF welded** seams (not needle-sewn as primary) | Excellent UV + rain | Default for outdoor NL summer |
| **Ripstop nylon + PU coating** (kite / tent weight) | Softer, matte, “soft sculpture” | **Sewn** + sealed tape; or sewn cover over PVC bladder | Good if coated; more fragile in wind | Gallery / calm days; needs skilled soft-goods maker |
| **Translucent PVC / clear + orange print** | Day candy + night glow possible | Welded | Good | Best if you want a cheap glow test |

**Avoid as primary:** uncoated cotton, cheap party-balloon foil, single-wall party bounce-house scrap without UV.

**Color:** match Glowberry amber → vermillion; solid dye-sub print or solid orange PVC + darker printed drupelet seams if budget allows.

## 4. Who makes it (not Artefact)

Studio Artefact is the **hard** path. Inflatable is a different trade:

| Role | What they do |
|------|----------------|
| **Pattern maker / industrial soft-goods designer** | Unwrap 3D mesh → flat panels (gore / segment patterns for drupelets) |
| **Welder (PVC shop)** *or* **seamstress / sail loft** | Weld vinyl **or** sew + tape ripstop |
| **Inflatable / event fabricator** | Turnkey: pattern + cut + weld + blower ports + bag |
| **You / tech** | Blower choice, anchors, power, install/tear-down |

### Who to ask (Canada / nearby)

Search terms: *custom inflatable sculpture*, *PVC welding shop*, *sail loft*, *theatrical soft goods*, *event inflatable manufacturer*.

| Region | Likely shops |
|--------|----------------|
| **Montreal / QC** | Industrial textile / awning / banner shops with **hot-air welders**; theatre soft-goods; Cirque-adjacent vendors (JPW-type custom industrial inflatables exist in broader NA) |
| **Toronto / ON** | Event inflatable makers; sail/loft stitchers |
| **Overseas** | China/Korea custom art inflatable factories (Choi’s world often uses specialist fabricators) — cheaper at large scale, longer lead, shipping + customs |

**Ask for:** quote on continuous-air fruit, ~**6–8 ft** first, orange PVC, one blower inlet at stem, ground loops, carry bag, 1 spare blower.

## 5. From your mesh → fabric

1. **Simplify** the 500 mm STL (decimate; keep drupelet silhouette readable at distance).  
2. **Scale** to target height (see tiers below).  
3. **Panelize** in Rhino/Blender/Pepakura-class tools or let the fabricator pattern it — berry = many curved gores, not one sphere.  
4. **Add:** stem/base flat for inlet; internal baffle optional (keeps bottom from ballooning); D-rings / webbing loops at low equator.  
5. **Cut** CNC or hand from nest; **weld/sew**; install zipper or Velcro service flap near blower.  
6. **Test** indoors; mark vents if over-pressurized.

## 6. Fan / blower

| Need | Spec direction |
|------|----------------|
| **Type** | Continuous-duty **centrifugal blower** (event-inflatable / bounce-house class), not a leaf blower |
| **Power** | Often **~0.5–1.5 hp** / few hundred watts for a 6–10 ft fruit; fabricator sizes CFM to volume + leak rate |
| **Noise** | Ask for “quiet” / residential-rated; hide in a **weather box** or under a fabric skirt at the stem |
| **Redundancy** | One primary + one spare on-site (fan death = deflation in minutes) |
| **Duct** | Flexible air sock from blower → stem collar; keep intake clear of sand/grass |
| **Power** | **AC plug** or small **generator** for remote shore; solar alone is awkward for continuous blower watts |

**Breathing effect (optional POC):** PWM or damper on blower for gentle inflate/deflate pulse — soft “alive” humor without LEDs. Keep amplitude small so it doesn’t look dying.

## 7. Scale tiers (inflatable only)

| Tier | Height | Role | Rough complexity |
|------|--------|------|------------------|
| **I-A** | ~**3–4 ft** | Studio / gallery / festival booth POC | Sewn ripstop or small PVC; desktop blower |
| **I-B** | ~**6–8 ft** | **Primary summer test** — plaza / park / shore day | Outdoor PVC + 1 blower + anchors |
| **I-C** | ~**10–12 ft** | Festival spectacle (Choi scale kinship) | Heavier fabric, 1–2 blowers, serious ballast |

Start at **I-B** unless you want a cheap I-A sew-up first.

## 8. Site, wind, safety (NL summer)

| Issue | Mitigation |
|-------|------------|
| Wind | Low center of gravity; **ballast** (sandbags / water barrels) + **guy lines** to ground stakes; deflate if gale warned |
| Salt / sand | PVC wipe-down; keep blower intake filtered |
| Touch / climb | Soft = climbable; post “do not climb” or accept soft damage; repair kit (patches + weld gun or tape) |
| Overnight | Deflate & bag **or** staffed continuous run; unsupervised night inflate is theft/vandal risk |
| Permissions | Easier for festivals / temporary permits than permanent FRP |

**Ephemeral by design:** install for a weekend → a month; document; pack out.
